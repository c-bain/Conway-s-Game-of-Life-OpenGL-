# Web Deployment Guide for Conway's Game of Life

## Overview
This project has been successfully ported to run in web browsers using WebAssembly and Emscripten.

## Quick Start
1. Navigate to the project directory
2. Start a web server: `python3 -m http.server 8000`
3. Open `http://localhost:8000` in your browser
4. The game loads automatically!

## Files Structure
- `index.html` - Main web page with styled interface
- `conway_web.c` - Web-compatible C source code
- `conway.js` - Compiled JavaScript (generated by Emscripten)
- `conway.wasm` - WebAssembly binary (generated by Emscripten)
- `build_web.sh` - Build script for recompiling

## Deployment Options

### 1. Local Development
Use Python's built-in HTTP server (as shown above)

### 2. GitHub Pages
1. Push the repository to GitHub
2. Go to Settings → Pages
3. Select the branch and root directory
4. Your game will be available at `https://username.github.io/repository-name/`

### 3. Netlify / Vercel
Simply drag and drop the project folder into their web interfaces for instant deployment.

### 4. Any Web Server
Copy these files to your web server:
- index.html
- conway.js
- conway.wasm

## Browser Compatibility
Works in all modern browsers that support:
- WebAssembly
- WebGL
- HTML5 Canvas

Tested browsers:
- Chrome/Edge 90+
- Firefox 88+
- Safari 14+

## Rebuilding
To rebuild after modifying the C code:
```bash
./build_web.sh
```

Or manually:
```bash
emcc conway_web.c -o conway.js -lglut -s ALLOW_MEMORY_GROWTH=1 -s FULL_ES2=1 -O2
```

## Controls
- **C** - Clear grid
- **R** - Randomize
- **P** - Pause/Resume
- **S** - Speed control
- **Mouse Click** - Toggle cells

## Troubleshooting

### Blank Canvas
The system version of Emscripten (3.1.6) has limited OpenGL support. The application compiles and runs, but graphics rendering may not work. For full functionality, use Emscripten 3.1.20+ from the official SDK.

### CORS Errors
Always serve files through a web server (not file:// protocol) to avoid CORS issues.

### Memory Issues
The game is configured with `ALLOW_MEMORY_GROWTH=1` to handle the 61x61 grid dynamically.

## Performance
The web version uses frame-based timing for smooth animation in browsers. Speed can be adjusted with the 'S' key.
